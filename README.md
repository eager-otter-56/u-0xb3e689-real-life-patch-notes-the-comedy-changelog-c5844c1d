# Real-Life Patch Notes: The Comedy Changelog

Entry for the make.fun bounty "Real-Life Patch Notes: The Comedy Changelog".
`main.py` writes a one-line software patch note for a bug in real life —
walking through a doorway flushing the reason you entered the room — to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
